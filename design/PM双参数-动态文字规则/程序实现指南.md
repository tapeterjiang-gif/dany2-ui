# PM2.5 / PM10 动态文字规则

量程均为0–999 μg/m³，按整数显示，不补前导零。两项始终使用Roboto SemiBold同一字号，首项x=26，共用基线y=223，整体最右边界x=440。

1. 从数字字号108px开始，测两项字宽、分隔符字宽与单位字宽。数字字距为-6×字号/108，只加在相邻数字之间；关闭kerning。
2. 分隔符字号为数字字号×82/108，单位固定30px。数字到分隔符、分隔符到第二项间距各10px，第二项到单位14px。
3. 计算总宽度：两项数字宽+分隔符宽+34px间隔+单位宽；超过414px时两项同步逐像素减小字号，直到放得下。不要按左右各自位数独立缩放。
4. slashX=26+首项宽+10；pm10X=slashX+分隔符宽+10；unitX=pm10X+第二项宽+14。最终检查unitX+单位宽≤440。
5. 当前官方Roboto SemiBold 3.015：每个数字advance为1170/2048 em，/为779/2048 em，μg/m³在30px为83.84765625px。相邻数字附加字距，再绘制；不要在最后一字后再加字距。
6. 当前1+1、1+2、2+1、1+3、3+1、2+2位均用108px；2+3与3+2位99px；3+3位84px。分隔符对应82、75.2、63.8px。

pm-text-layout.js可直接用于网页，亦可按同样计算移植至设备。参数只适用于交付的Roboto SemiBold；如字体引擎按像素取整，应按实际测宽结果重新检查右边界。若改字体或字距，重新计算全部字号，不强行保留84px下限。

数字更新时同一帧提交文字和位置，避免数字与单位错帧。无效数据按产品缺测规则处理，不把缺测显示为0。输入负值、超量程、浮点数的处理由数据层完成；演示参考代码将数值限制到0–999并截为整数。

已检查0、9、10、99、100、999两项组合的36个边界案例，含整像素向上取整后右边界，均不溢出。字体文件与SIL OFL许可见开源字体资源包。
