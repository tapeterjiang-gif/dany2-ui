# Dany 2 温度 评级指示器

等级数：7；从上到下：热 → 暖 → 微暖 → 中性 → 微凉 → 凉 → 冷。

所有PNG的1x尺寸均为16×102，统一放在502×410屏幕的 (457,130)。4x文件为64×408，缩回1x显示时仍使用(457,130)；仅在2008×1640画布上使用(1828,520)。

两种接入方式：
1. 直接显示 state-*.png：每个文件已包含分段条与对应玻璃高光，按等级替换一张即可。
2. 分层显示：先绘制 rating-base.png，再同坐标绘制 highlight-state-*.png。高光不含底色，方便淡入淡出。不要再同时叠加完整状态图。

切图含透明留白，不能自动裁边。基础色条位于屏幕(461,132)，8×98；玻璃高光宽11.2，左侧x=459.4。各等级纵向位置见坐标与等级.json，程序不必另计算贴图偏移。

滑动动效：底色与高光使用同一横向缩放中心(465,181)，宽度80%至100%，高度保持；高光稍晚显现。显示在黑色背景上，采用Alpha混合。没有评级文字或阴影。

温度为PMV七档冷热感，不应只根据温度推导等级。
