# 配置等待：呼吸与旋转

Matter添加中每1600ms一圈（225°/秒），正在清除每1200ms一圈（300°/秒）。均顺时针、匀速，白色90°短弧、圆角端点；灰色底环静止。进入时160ms线性淡入，循环首尾不暂停，不缩放、不闪烁。不要对每圈角度使用ease-in-out，以免每圈出现减速或顿挫。

青萍/米家添加中恢复原App图标呼吸光晕，不显示圆环。图标88×88px，左上(207,132)，光晕中心(251,176)，2.4秒一个周期，ease-in-out，缩放104%→132%→104%；图标本身不缩放、不旋转。等待添加页保持原呼吸效果。Matter添加中为(217,103)68×68；三种清除页均(219,111)64×64。全部画布正方形，旋转原点必须为画布中心。4x切图仅提高分辨率，显示坐标仍按原生像素。

逐帧 angle = ((elapsedMs % periodMs) / periodMs) × 360。优先60fps，资源有限可30fps；根据时间计算角度，不按帧数累加。waiting-motion.js提供纯计算函数。先画静止track，再旋转白色arc；App图标与文字均不旋转。

收到真实成功、失败或清除完成事件后立即退出循环、进入对应页面，不凑满一圈、不强制最低等待时间。此动画不表示已完成百分比。长按触摸条6秒的倒计时仍显示真实进度，不套用等待循环。清除开始后不因松手取消。

网页预览支持暂停；离开可视区或切后台暂停，系统要求减少动态效果时显示静态弧线。动效模块不更改真实设备状态。
