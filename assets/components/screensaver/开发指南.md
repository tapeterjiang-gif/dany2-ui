# Dany 2 屏保开发指南

2026-11-21定稿。502×410原生PNG、2008×1640高清PNG，纯黑背景，R82圆角外透明。五行依次为温度、湿度、CO₂、PM2.5、PM10。

## 图标与字体

五个图标使用36×40透明白色Alpha切图，程序按当前读数等级着色，1x及4x在切图目录。可见宽度统一30px、可见左沿x55.25，PNG左上x54。CO₂使用环境评级指南定义的Material Symbols Rounded air；PM共用blur_on点阵拓扑，底部2.5/10为12px Roboto SemiBold。点阵圆点及温湿度图标比例针对小屏微调。来源：https://tapeterjiang-gif.github.io/environment_rating/design.html

五个图标按可见Alpha下沿与数字下沿对齐，不按透明画布下沿定位。各PNG顶部y依次76 / 150.75 / 217.25 / 278.75 / 346.75，完整坐标见布局JSON。

字体：顶部时间与24 HOURS均Roboto Regular 26px；读数Roboto SemiBold 48px；单位Roboto Regular 18px；PM图标中的2.5/10为12px SemiBold（已包含于PNG，无需再次绘字）。字体及SIL OFL许可在字体目录。

## 趋势与平均线

五行趋势等宽：每行24柱，x=276+小时序号×7.82，柱宽6.2px、顶部R1.5、底部直角，右端462.06，最大高49px。柱色取该小时评级，顶部不透明、底部84%不透明。barTop=baseline−(value−axisMin)/(axisMax−axisMin)×49。提供7×2px柱顶Alpha蒙版（实际形状6.2px宽），不提供整张趋势切图。

示例轴域：温度20..28、湿度40..70、CO₂0..2500、PM分别0..60。实际超出时扩展轴域并同步重算。缺测不画柱，不以0参与均值。

平均线x276..462，线宽0.7px、实线4px/间隔4px、平端点、72%不透明。均值等级色混入16%白色，无描边、无数值。meanY=baseline−(validMean−axisMin)/(axisMax−axisMin)×49。温度使用有效小时PMV均值评级。

## 等级色与示例数据

图标使用当前等级色；柱按各小时等级、均线按有效均值等级着色。温度需输入PMV，不能单独由温度推断。湿度<40/40..60/>60为#D97706/#16A34A/#1D4ED8。CO₂<1000/1000..2000/>2000为#16A34A/#65A30D/#EA580C。

PM2.5上限5/15/50/90/140，PM10上限15/45/120/195/270，包含等号；颜色依次#16A34A/#65A30D/#CA8A04/#EA580C/#DC2626/#7E22CE。温度PMV沿用温度读数页规则。

参考读数24.6°C、56%RH、2168ppm、26μg/m³、17μg/m³。PM2.5历史包含绿色、黄绿色和黄色。24 HOURS表示截至最近完整小时的24小时滚动窗口。生产接入真实时钟、数据、缺测处理与评级。

## 交互与复现

默认连续30分钟无顶部触摸条操作后进入屏保（1800秒）。点击或滑动触摸条重新计时；传感器、趋势图及时间自动更新不重置计时。配置、配对和长按清除过程中暂停进入屏保。顶部触摸条滑动唤醒，返回此前读数页；设备屏幕不支持触摸。网页“进入屏保/返回”仅为演示。
运行npm install @resvg/resvg-js fontkit后执行node 预览绘制.cjs，输出PNG到预览/。程序只复现设计示例；生产接入实时数据、真实字体测宽、缺测处理与评级规则。
